  • [ PLATFORM ] itch.io Wants to Pull Your Builds Straight Off Steam. A New "butler steam-sync" Command Is in Testing, and the Manual Is Already Up.

    "We're looking for testers! Our butler CLI will soon have a steam-sync command to allow you to synchronize builds from Steam -> itch.io," the platform's account posted at 20:52 UTC on Wednesday, September 16, with a link to a manual page that had not existed the day before. The ask is narrow: you should "already have a game published on Steam," an itch.io account "where you'd like to publish or update the game," and be "comfortable downloading and running command line tools" — "This is command line *only* for now, but in the future we may explore adding it to the apps Upload tab." Testers join the itch.io Discord and ping leafo in #itchio-talk. What the tool does is the part that has been requested on the butler forum for years: butler steam-sync logs in to Steam as you, pulls the depots of an app you publish, sorts them into one directory per platform — windows, linux, mac, or per architecture, windows-64, if any depot declares one — and pushes each as a channel with butler push, stamping the Steam build id as the itch.io version so running the same build twice does nothing. DLC depots, depots shared from another app and non-English language packs are left out unless you --map them to a channel by hand; a --cache-dir keeps depot downloads between syncs so only the Steam-side delta comes down and only the itch-side patch goes up; a TOML config file with a [[sync]] block per app makes the whole thing a single periodic command, and there are flags and environment variables for running it from CI without a saved login. Setup is three commands — steam-login, which shows a QR code for the Steam mobile app so no password passes through butler, steam-key for a Steamworks publisher Web API key, and the sync itself, which refuses any app the key's partner group does not control — and the manual is unusually plain about the trade-off: "Steam has no scoped API for downloading a game's files, so butler logs in as your Steam account the same way the Steam client does. The token Steam hands back grants full access to that account, not just to downloads." Everything Steam-side runs locally, the token is never sent to itch.io, and there is a steam-logout. It also anticipates the objection the first Bluesky reply raised — "I would volunteer to test it if itch and steam versions of my games didn't have to be different (because of the steam api usage)": if a channel contains steam_api64.dll, libsteam_api.so or steam_appid.txt, butler prints a warning that the build may not run for players without Steam, and suggests syncing a Steam branch with the integration switched off. Private branches work with a password, except the newer kind that withholds the depot list, which fails with "has no manifest on branch." The commands are hidden from butler --help for now, the docs page calls the feature experimental, and nothing has landed in the public GitHub repository — its last release, v15.31.0 on September 1, was the headless-launch work that shipped with the itch app two weeks ago. Read with the jam submission requirements below and the dashboard sort-and-filter update the week before, it is the third developer-tooling change in a fortnight, and the first that reaches outside itch.io: it is a pitch to the developer who has a Steam page and has never bothered with an itch page, that keeping one costs a cron job. The post had 74 likes and 19 reposts by Thursday morning. Source: Syncing builds from Steam — The butler manual · itch.io on Bluesky · butler push docs · butler releases on GitHub · itch.io Discord

Generative AI disclosure: require entrants to have filled out the AI disclosure on their project page, or accept only projects whose disclosure says no generative AI was used. Pricing: require a free download — at least one file downloadable without paying, demos of paid projects included — or accept only projects with no price and no paid files. Platforms: require files for Windows, macOS, Linux, Android or browser, any one of the selected or all of them, where "browser means a playable HTML build." Timing: accept only projects created after the jam started, or whose first file was uploaded after it started. Not submitted to another jam. The mechanism is a checklist in the submit dialog, "and only projects that pass every requirement can be submitted"; the checks run at submission time, "so changing them later does not affect existing entries."   • [ RELEASE ] A Free Art Gallery You Ride a Train Through. The Zium Society's Fifth Exhibition Is Out, and Every Donation Is Split Between the Artists.

    "The Zium Railway is out today! Available as a free download on itch," Jacob Potterfield posted on Sunday afternoon, "if you're interested in exploring the video game medium as a immense canvas for art experimentation." A zium — the word is the collective's own, "kind of like a zine, but the museum video game version" — is a virtual gallery game in which artists from around the world each get a room, and The Zium Society has been making them on itch.io since The Zium Museum, through The Zium Garden, The Zium Gallery and last year's The Zium Exposition, the last of which sits at 5.0 stars from 34 ratings. The Zium Railway is the fifth mainline exhibition and, counting this spring's literary journal The Zium Digest, the sixth collaborative project. The change this time is the building. Instead of a museum, curator Michael Berto handed the whole world to Potterfield — the artist behind Ramblemoor, who built the introductory level of the Exposition — and the result is a hand-crafted open world called Lyptch, "the picturesque Valley of the Underground Mountain," explorable on foot or by the Z Train, with a station for each artist. Every station holds a Process Gallery, the series' signature feature, of sketches, early screenshots and background notes, and then an entrance into the artist's actual scene. The artists are Ada Null, Charlotte Madelon, Christopher Ferris, Farfama, John Flannelly & Virtual Neighbors, Julian Palacios, Zilasaule, Pippin Barr — who was in the contributor list of the very first Zium Museum — plus Potterfield and Berto themselves, a deliberately small pool against the 20, 30 or 40-plus artists of the tentpole exhibits. Berto's release-day letter explains why: it let him try something he had wanted to for a while, revenue share. All donations to the itch.io page during the first year are split equally between the featured artists, Berto's own share being The Zium's share, "so any donation you make to The Zium goes directly to the artists that worked on it." Donors of $5 or more also get A Beautiful Moment Will Occur, a feature-length "software film" by Berto — "a game you watch but don't play" — with its soundtrack on Bandcamp. The letter is unusually candid on one more point. Did the project use AI? "Not really, though the answer is, categorically; yes": Berto used it for programming and code assistance, accepted no AI artworks, and says none of the artists used it in their work — "In general, on the AI issue … I am Zwitzerland." The idea came from Farfama, who suggested a Zium "that was like a railway, and that each artist could have their own station," and the build ran from roughly mid-2025 on a "take as long as everyone needs" schedule. Windows only, name your own price, and the page is still marked "In development"; the first six ratings in are all five stars.
